# JALNYAY AI Android app

This is a native Android shell that packages the supplied JALNYAY AI experience as a mobile app. All dashboard, complaint, priority, tanker, and service-hub interactions run locally in the app.

## Build an APK

1. Open this folder in Android Studio (Ladybug or newer).
2. Let Android Studio install the requested Android SDK/Gradle components.
3. Choose **Build → Build APK(s)**.
4. Find the debug APK in `app/build/outputs/apk/debug/`.

The demo stores its data locally on the device. Use Android Studio's Emulator or connect an Android phone with USB debugging enabled to run it.
